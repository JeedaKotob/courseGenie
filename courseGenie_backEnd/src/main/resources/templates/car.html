ii. CLOs Assessment

All course learning outcomes (CLOs) are required to be assessed and evaluated in each assessment cycle for all programs. Direct assessment is expected of all CLOs.

Assessments at the course and program levels are related as improvements at the course level will lead to improvements at the program level. Therefore, benchmarks are used for any CLO direct  assessment to assess the Program Learning Outcomes (PLOs). Depending on your program assessment plan, one or more benchmarks can be used. You must complete section III if this course is part of the PLOs assessment plan cycle.
